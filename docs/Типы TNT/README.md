# Типы TNT

Каждый тип TNT описывается в YAML-файле под ключом `tnts.<id>`. Один файл может содержать несколько типов.

## Структура типа

```yml
tnts:
  <id>:
    enabled: true
    item:       # внешний вид предмета
      ...
    ignite:     # поведение при поджиге
      ...
    craft:      # крафт (опционально)
      ...
    hologram:   # голограмма над горящим TNT (опционально)
      ...
    explosion:  # параметры взрыва
      ...
```

## Разделы

* [Предмет (item)](01-item.md) — материал, название, лор, свечение.
* [Поджиг (ignite)](02-ignite.md) — фитиль, гравитация, бросок, способы поджига.
* [Взрыв (explosion)](03-explosion.md) — радиус, урон, блоки, огонь, команды.
* [Голограмма и визуал](04-visual-hologram.md) — текст над TNT, анимация свечения.

## Идентификатор типа

* `id` — уникальная строка в нижнем регистре (например, `default`, `nuclear`, `sticky`).
* Используется в команде `/hypertnt give` и для внутренней пометки предмета.

> [!WARNING]
> Если два файла объявляют один и тот же `id` — будет загружен тот, что идёт последним в `tnts.sources`.
