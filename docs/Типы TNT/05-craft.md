# Крафт (craft)

Секция `craft` добавляет **крафт рецептом** для конкретного типа TNT.

Рецепт создаётся как `ShapedRecipe` и выдаёт **предмет этого типа TNT** (тот же, что выдаёт команда `/hypertnt give`), с внутренней меткой плагина.

> [!NOTE]
> По умолчанию крафт выключен: `craft.enabled: false`.

## Синтаксис

```yml
<id>:
  craft:
    enabled: false
    shape:
      - "GGG"
      - "GTG"
      - "GGG"
    ingredients:
      G: GUNPOWDER
      T: TNT
```

---

## Параметры

### `enabled`

* `enabled` (опционально) — включить/выключить регистрацию рецепта.
* По умолчанию: `false`.

### `shape`

* `shape` (опционально) — форма крафта (3 строки), как в стандартных шейп-рецептах Minecraft.
* Должно быть **ровно 3 строки**, иначе рецепт **не зарегистрируется**.

Пример:

```yml
shape:
  - "GGG"
  - "GTG"
  - "GGG"
```

> [!TIP]
> Рекомендуется использовать строки длиной 3 символа (классическая сетка 3x3), например `"ABC"`.

### `ingredients`

Сопоставление **символа из `shape`** → **материал**.

* Ключ — один символ (например `G`, `T`, `#`). Если ключ длиннее 1 символа — он будет проигнорирован.
* Значение — Bukkit-имя материала (например `GUNPOWDER`, `TNT`, `NETHER_STAR`).
* Если материал указан неверно — ингредиент будет проигнорирован.

Пример:

```yml
ingredients:
  G: GUNPOWDER
  T: TNT
```

---

## Как работает при перезагрузке

При `/hypertnt reload` плагин:

1) удаляет ранее зарегистрированные рецепты `hypertnt_<id>` для всех загруженных типов
2) заново регистрирует рецепты для типов, у которых `craft.enabled: true`

---

## Примеры

### Включить крафт для типа

```yml
default:
  craft:
    enabled: true
    shape:
      - "GGG"
      - "GTG"
      - "GGG"
    ingredients:
      G: GUNPOWDER
      T: TNT
```
