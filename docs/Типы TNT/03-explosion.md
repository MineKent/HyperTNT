# Взрыв (explosion)

Секция `explosion` определяет все параметры взрыва: радиус, урон по сущностям, поведение блоков и постэффекты.

## Синтаксис

```yml
tnts:
  <id>:
    explosion:
      radius: 6.0
      damage:
        enabled: true
        max-damage: 24.0
        min-damage: 0.0
        exposure: 1.0
      quality:
        rays: 16
        strength-multiplier: 1.0
        resistance-multiplier: 1.0
      blocks:
        default:
          mode: BREAK
          drop-chance: 1.0
        per-material:
          OBSIDIAN:
            mode: IGNORE
          CHEST:
            mode: BREAK
            drop-chance: 1.0
      post:
        set-fire: false
        fire-chance: 0.2
        commands: []
```

---

## Параметры

### `radius`

* `radius` (опционально) — радиус взрыва в блоках. По умолчанию `6.0`.

---

### `damage`

Настройка урона по живым сущностям в зоне взрыва.

* `enabled` (опционально) — включить урон. По умолчанию `true`.
* `max-damage` (опционально) — максимальный урон (в центре взрыва). По умолчанию `24.0`.
* `min-damage` (опционально) — минимальный урон (на краю радиуса). По умолчанию `0.0`.
* `exposure` (опционально) — множитель экспозиции (0.0–1.0): учитывает блоки между взрывом и целью. По умолчанию `1.0`.

Урон масштабируется линейно между `min-damage` и `max-damage` в зависимости от дистанции до центра, умноженной на `exposure`.

```yml
damage:
  enabled: true
  max-damage: 40.0
  min-damage: 5.0
  exposure: 0.8
```

---

### `quality`

Параметры точности расчёта взрыва (ray-casting).

* `rays` (опционально) — количество лучей для расчёта. Минимум `2`. По умолчанию `16`. Чем больше — тем точнее и тяжелее.
* `strength-multiplier` (опционально) — множитель силы взрыва. По умолчанию `1.0`.
* `resistance-multiplier` (опционально) — множитель сопротивления блоков. По умолчанию `1.0`.

> [!WARNING]
> Большое значение `rays` (>32) на крупных взрывах может вызывать лаги на слабых серверах.

---

### `blocks`

Управление разрушением блоков взрывом.

#### `blocks.default`

Правило по умолчанию для всех блоков.

* `mode` (опционально) — режим разрушения. По умолчанию `BREAK`.
* `drop-chance` (опционально) — шанс дропа (0.0–1.0). По умолчанию `1.0`.

#### Режимы (`mode`)

| Значение | Описание                              |
|----------|---------------------------------------|
| `BREAK`  | Блок разрушается (с учётом drop-chance) |
| `IGNORE` | Блок не разрушается взрывом           |

#### `blocks.per-material`

Переопределение правил для конкретных материалов. Ключ — Bukkit-имя материала.

* `mode` (опционально) — режим для этого материала. Если не указан — берётся из `blocks.default`.
* `drop-chance` (опционально) — шанс дропа. По умолчанию берётся из `blocks.default`.

```yml
blocks:
  default:
    mode: BREAK
    drop-chance: 0.5
  per-material:
    OBSIDIAN:
      mode: IGNORE
    CHEST:
      mode: BREAK
      drop-chance: 1.0
    BEDROCK:
      mode: IGNORE
```

---

### `post`

Постэффекты после взрыва.

* `set-fire` (опционально) — поджигать блоки в зоне взрыва. По умолчанию `false`.
* `fire-chance` (опционально) — вероятность возгорания каждого блока (0.0–1.0). Работает только при `set-fire: true`. По умолчанию `0.0`.
* `commands` (опционально) — список консольных команд, выполняемых после взрыва. По умолчанию пустой список.

```yml
post:
  set-fire: true
  fire-chance: 0.3
  commands:
    - "say Взрыв произошёл в мире {world} на {x} {y} {z}"
```

> [!NOTE]
> В `commands` можно использовать плейсхолдеры координат взрыва (зависит от реализации плагина).
