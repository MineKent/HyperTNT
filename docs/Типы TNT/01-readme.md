# Типы TNT

Каждый тип TNT описывается в YAML-файле. Один файл может содержать несколько типов — каждый тип является ключом верхнего уровня.

## Структура типа

```yml
<id>:
  enabled: true
  item:       # предмет в инвентаре (материал, название, лор)
    ...
  ignite:     # поведение при поджиге (фитиль, физика, бросок, разрешённые методы)
    ...
  craft:      # крафт (опционально)
    ...
  visual:     # визуальные эффекты горящего TNT (свечение, голограмма)
    ...
  explosion:  # параметры взрыва
    ...
```

## Разделы

* [Поджиг (ignite)](02-ignite.md) — фитиль, физика движения, бросок, способы поджига.
* [Крафт (craft)](03-craft.md) — рецепт крафта для типа TNT.
* [Голограмма и визуал](04-visual-hologram.md) — свечение и текст над горящим TNT.
* [Взрыв (explosion)](05-explosion.md) — радиус, урон, блоки, постэффекты.

## Идентификатор типа

* `id` — уникальная строка в нижнем регистре (например, `default`, `nuclear`, `sticky`).
* Используется в команде `/hypertnt give` и для внутренней пометки предмета.

> [!WARNING]
> Если два файла объявляют один и тот же `id` — будет загружен тот, что идёт последним в `tnts.sources`.
