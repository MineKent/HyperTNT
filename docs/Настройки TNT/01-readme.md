# Типы TNT

Каждый тип TNT описывается в YAML-файле. Один файл может содержать несколько типов — каждый тип является ключом верхнего уровня.

## Структура типа

```yml
<id>:
  enabled: true
  item:         # предмет в инвентаре (материал, название, лор)
    ...
  ignite:       # поведение при поджиге (фитиль, физика, бросок, разрешённые методы)
    ...
  craft:        # крафт (опционально)
    ...
  conditions:   # условия активации (опционально)
    - "..."
  conditions-fail-message: "..."
  visual:       # визуальные эффекты горящего TNT (свечение, голограмма, звуки)
    ...
  explosion:    # параметры взрыва
    ...
```

## Идентификатор типа

* `id` — уникальная строка в нижнем регистре (например, `default`, `nuclear`, `sticky`).
* Используется в команде `/hypertnt give` и для внутренней пометки предмета.

### Специальный тип: `_default_`

Если создать тип с id `_default_`, то он **не добавляет новый отдельный предмет TNT**, а **переопределяет поведение ванильного TNT** (Minecraft TNT):

* кастомный взрыв (`explosion`)
* визуалы/голограмма/свечение (`visual.*`)
* кастомный звук и частицы взрыва (`visual.sounds`, `visual.particles`)
* крафт ванильного TNT (`craft.*`)

> [!NOTE]
> Для `_default_` секция `item` опциональна. Она нужна только если вы хотите изменить предмет, который получается из крафта/рецепта (например, чтобы ванильный крафт выдавал "помеченный" TNT).

> [!WARNING]
> Если два файла объявляют один и тот же `id` — будет загружен тот, что идёт последним в `tnts.sources`.
