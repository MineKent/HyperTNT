# Предмет (item)

Секция `item` описывает внешний вид TNT-предмета в инвентаре: материал, название и лор.

> [!NOTE]
> Свечение горящей TNT-сущности настраивается в секции [`visual.glow`](04-visual-hologram.md#свечение-visualglow), а не здесь.

## Синтаксис

```yml
<id>:
  item:
    material: TNT
    custom_model_data: 1234
    enchanted: true
    name: "&c&lHyperTNT"
    lore:
      - "&7Особый динамит"
      - "&7Время до взрыва: &c{fuse}s"
```

## Параметры

### `material`

* `material` (опционально) — Bukkit-имя материала предмета. По умолчанию `TNT`.

Примеры допустимых значений: `TNT`, `GUNPOWDER`, `FIRE_CHARGE`, `NETHER_STAR`.

### `custom_model_data`

* `custom_model_data` (опционально) — число для `CustomModelData` (ресурс-паки/кастомные модели предметов).
* По умолчанию: не задаётся.

### `enchanted`

* `enchanted` (опционально) — сделать предмет визуально "зачарованным" (эффект глитча, без реальных чар).
* По умолчанию: `false`.

### `name`

* `name` (опционально) — отображаемое название предмета в инвентаре. Поддерживает `&`-коды цветов и PlaceholderAPI.

### `lore`

* `lore` (опционально) — список строк описания предмета в инвентаре. Поддерживает `&`-коды и плейсхолдер `{fuse}`.

Доступные плейсхолдеры в `lore`:

| Плейсхолдер | Описание                        |
|-------------|---------------------------------|
| `{fuse}`    | Время горения фитиля в секундах |
