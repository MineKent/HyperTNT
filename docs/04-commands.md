# Команды

Все команды плагина доступны через `/hypertnt` (алиас: `/htnt`).

## Права доступа

| Право           | Описание                          | По умолчанию |
|-----------------|-----------------------------------|--------------|
| `hypertnt.admin` | Доступ к командам `give`, `reload` | Операторы (op) |

Меню типов TNT доступно всем игрокам, но выдача TNT и админ-действия требуют `hypertnt.admin`.

---

## Команды

### `/hypertnt`

Для игрока без аргументов открывает меню типов TNT. Для консоли выводит справку.

```bash
/hypertnt
```

---

### `/hypertnt give <игрок> <тип> [количество]`

Выдаёт предмет кастомного TNT указанному игроку.

* `<игрок>` (обязательно) — ник онлайн-игрока.
* `<тип>` (обязательно) — идентификатор типа TNT (например, `default`).
* `[количество]` (опционально) — количество предметов. По умолчанию `1`.

**Требует:** `hypertnt.admin`

```bash
/hypertnt give Steve default 5
/hypertnt give Alex nuclear
```

> [!WARNING]
> Игрок должен быть онлайн. Выдача оффлайн-игрокам не поддерживается.

---

### `/hypertnt reload`

Перезагружает `config.yml`, `messages.yml` и все файлы типов TNT без перезапуска сервера.

**Требует:** `hypertnt.admin`

```bash
/hypertnt reload
```

> [!TIP]
> Используй после изменения любого YAML-файла плагина. Новые типы TNT будут доступны сразу после перезагрузки.

## Tab-completion

Плагин поддерживает автодополнение по Tab:

| Позиция аргумента | Подсказки                         |
|-------------------|-----------------------------------|
| 1-й аргумент      | `give`, `reload`                  |
| 2-й аргумент (give) | Список онлайн-игроков           |
| 3-й аргумент (give) | Список доступных типов TNT      |
