# HyperTNT

Плагин для Bukkit/Paper, позволяющий создавать кастомные типы динамита с гибкой настройкой взрыва, поджига, визуальных эффектов и крафта.

## Что умеет (MVP)

* Создавать неограниченное количество типов кастомного TNT через YAML-файлы.
* Гибко настраивать взрыв: радиус, урон, поведение блоков по материалу, огонь, команды после взрыва.
* Управлять способами поджига: кремень, огненный шар, редстоун, огонь, цепная реакция.
* Бросать TNT правым кликом с настраиваемой скоростью.
* Отображать голограмму над горящим TNT с обратным отсчётом.
* Подсвечивать TNT кастомным цветом свечения (включая анимацию смены цвета).
* Задавать кастомный крафт для каждого типа.
* Выдавать TNT командой `/hypertnt give`.

## Базовая логика

1. Плагин читает `config.yml` и список файлов-источников из раздела `tnts.sources`.
2. Каждый YAML-файл содержит один или несколько типов TNT под ключом `tnts.<id>`.
3. Игрок получает предмет TNT (через команду или крафт) — предмет помечается внутренним PDC-тегом с `id` типа.
4. При поджиге создаётся `PrimedTNT` с нужным временем горения; запускается голограмма и свечение.
5. При взрыве плагин рассчитывает урон и разрушение блоков по правилам из `explosion`-секции.

### Легенда

* `<...>` — обязательный аргумент
* `[...]` — необязательный аргумент
